# GreenCart Frontend

GreenCart is a sustainability-focused shopping application that helps users explore products and compare their sustainability scores.

## Technologies Used

- React
- Vite
- JavaScript
- React Router
- CSS

## Prerequisites

- Node.js and npm
- GreenCart backend running locally

## Installation

Install the frontend dependencies:

```bash
npm install
```

## Run the Application

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in the terminal, usually `http://localhost:5173`.

## Backend

The frontend communicates with the GreenCart FastAPI backend. Make sure the backend is running and its API URL is configured correctly.

## Features

- Browse sustainability-focused products
- Search and filter products by category
- Compare up to three products
- View sustainability scores and evidence coverage
- Explore product details and descriptions
